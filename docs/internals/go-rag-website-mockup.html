Why

As frictionless as git init.

A local RAG database shouldn't need infrastructure. Install the binary, run go-rag init, and you have a working system.

01

No cloud, no keys

Everything runs on your machine. A built-in embedding model handles ingest and query out of the box; point it at a local Ollama instance later for higher-quality embeddings and reranking — never required.

02

No Docker required

A single static binary, built with CGO_ENABLED=0. Copy it, run it, done.

03

Loopback by default

Every transport binds to 127.0.0.1 unless you explicitly opt in to exposing it.

Features

Built for retrieval quality, not just retrieval.

Every piece exists to answer one question honestly: is this result actually relevant, and can you trust it?

Hybrid retrieval (RRF)

Fuses BM25 keyword and vector semantic ranked lists with Reciprocal Rank Fusion, one tunable constant, honoured identically across CLI, REST, gRPC, and MCP.

Built-in embedding model

Ships with an embedding model baked into the binary — ingest and query work fully offline from the first run, no external service to install first.

Isolated vaults

Each vault gets its own config, embedding model, and indexes — isolated by key-space prefixes within a single shared Pebble instance, not a separate database per vault. No cross-vault contamination, without the overhead.

Embedding drift monitoring

Pins the embedding profile a corpus was built under and checks it at boot — hard drift degrades the daemon before a query, not after recall collapses silently.

MCP daemon

A background daemon serves MCP over HTTP with 10 tools — wire it into Claude Desktop and query your vault directly from the model.

Optional Ollama enrichment

Point go-rag at a local Ollama instance for higher-quality embeddings and cross-encoder reranking — an upgrade you opt into, never a prerequisite to get started.

How retrieval works

Two lists become one.

Hybrid mode fuses the BM25 and vector ranked lists with a single symmetric constant. Hover a row to see how each list contributes to the final ranking.

score(d) = Σ 1/(k + rank)  ·  k = 60 by default

The same k applies to both lists, so the fusion stays reviewable and matches the standard RRF formula. Tune it per corpus with go-rag config set rrf_k 120, or override it for a single query with --rrf-k 30.

Architecture

Layered, and each layer does one job.

A single binary, but not a single blob — the CLI, ingest pipeline, retrieval, and storage layers are cleanly separated internally.

Quickstart

Three commands to a working system.

Requirements

Go 1.22+

Build from source. That's it — the embedding model ships in the binary; Ollama is an optional upgrade, not a prerequisite.

make build
Ingest

Point it at a folder

Idempotent, with a progress bar. PDF, Word, Markdown, and text all supported.

./bin/go-rag init ./bin/go-rag add ./my-docs/
Query

Ask it something

Hybrid search with source-cited results, reranked by default.

./bin/go-rag query "how does X work?"
CLI reference

Every command, grouped by what you're doing.

Ingest & query

go-rag initInitialize a new RAG database
go-rag add <path>Add files or directories (idempotent; progress bar)
go-rag scan [--watch]Scan for changes (fsnotify + polling)
go-rag query "<q>"Hybrid semantic + keyword search
go-rag statusDaemon + database statistics and health
go-rag config [get|set]View or change configuration

Inspect & maintain

go-rag files [--json]List ingested file paths
go-rag dirs [--json]Per-directory file + chunk counts
go-rag reprocess <path>Force re-ingest a directory, bypassing dedup
go-rag migrateRe-embed all documents to the current model

Vaults

go-rag vault create <name>Create a new isolated vault
go-rag vault listList vaults with doc counts, model, daemon status
go-rag vault clone <src> <dst>Clone a vault
go-rag vault export <name>Export a vault as a tar archive
go-rag vault import <name>Import an existing database, no re-ingestion
go-rag --vault <name> <cmd>Run any command against a specific vault

Daemon

go-rag startStart the daemon in the background (loopback by default)
go-rag stopStop the running daemon
go-rag mcpstdio→HTTP proxy, bridges Claude Desktop to the daemon

Retrieval quality

Measured against BEIR, not assumed.

Instruction prefixes help most where query/passage asymmetry is high — the benchmark shows the contrast rather than a single averaged number.

Security

Loopback-only, by default.

go-rag never silently exposes your document vault to the network. Every transport binds to 127.0.0.1 — reaching further requires an explicit, logged opt-in.
